# What the study costs, and what $950 buys

Funding on hand: **$950**. Spent as of 2026-09-19: **$103.06**.
`STUDY_BUDGET_USD=950` is set in `.env`, so `spend.check_budget()` raises before
the next paid call once the ledger reaches it. Nothing is lost at the stop:
every finished run is on disk and `--resume` picks up.

## First: the prices in this file were wrong until 2026-09-19

`spend.py` carried a comment claiming its rates had been "checked against each
vendor's published rates". They had not been. All four were wrong, in different
directions, so the errors did not cancel:

| model | table said | vendor's page says | |
|---|---|---|---|
| gpt-5.6-luna | $1.00 / $6.00 | $0.20 / $0.90 | 10x too high |
| gemini-3.5-flash | $0.75 / $4.50 | $1.50 / $9.00 | **2x too LOW** |
| claude-sonnet-5 | $3.00 / $15.00 | $2.00 / $10.00 | 1.5x too high |
| claude-opus-5 | $15.00 / $75.00 | $5.00 / $25.00 | 3x too high |

Restating all 816 ledger rows from their stored token counts moved the total
from $127.97 to **$103.06** — grading $61.55 → $20.52, letters $11.29 → $6.82,
retrieval $55.12 → **$75.72** (Gemini was the one being under-reported).

There is now no silent fallback: an unpriced model raises `UnknownPrice` and the
dry run fails before a paid run starts. `spend.VERIFIED` carries the date and
`spend.SOURCES` the three vendor pages the numbers came from.

## Finishing the pilot: ~$120

61 retrievals $76, 120 letters $16, 120 grades $10–21, ~2,000 searches $10.
The pilot lands at about **$221** all-in, leaving **~$729**.

## Gemini costs more than the other three arms put together

$1.89 of the $2.43 per-case retrieval cost is Gemini — **78%**. Two things
compound: Gemini 3.5 Flash tripled its price, and it makes 45 searches per case
against ChatGPT's 15. Its earlier $0.35/case was the price of an arm we were
truncating at 40 tool calls; $1.89 is the honest figure.

That single line decides the size of the main study:

| design | cost | fits $729? |
|---|---|---|
| 400 cases, 4 arms | $1,392 | no |
| 300 cases, 4 arms | $1,044 | no |
| 250 cases, 4 arms | $870 | no |
| 200 cases, 4 arms | $696 | yes, $33 spare |
| **350 cases for ChatGPT / Claude-free / Ortho, Gemini on 100 of them** | **$637** | **yes, $92 spare** |
| 400 cases, drop Gemini entirely | $464 | yes, $265 spare |

**Recommended: the fifth row.** The two comparisons carrying the argument get
full n — ChatGPT vs OrthoAppeals, because ChatGPT free is what patients actually
use, and Claude-free vs OrthoAppeals, because it holds the model constant and so
isolates architecture from model. Gemini is a third comparator; 100 paired cases
is ample to say whether it behaves like ChatGPT or like OrthoAppeals, and it is
the only line item where cutting n buys back real money.

Do **not** shrink Gemini's tool budget to save money. An unequal ceiling across
arms is what produced three truncated Gemini runs on 2026-09-19, and the bias
ran toward the result we want to be true.

## The number still to watch

Grading has used 478 Opus calls for 119 graded letters — **4.02 calls per
letter**. Almost all of that was the period when the grader returned incomplete
JSON and every incomplete grade was retried. That is fixed; the forward rate
should be near 1.1. Every table above assumes 2.0 to be safe. Measure it
deliberately: `grade_letters.py --limit 20`, then divide the grading calls added
to the ledger by 20 before committing the rest.
